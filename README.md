一只可爱的桌面月薪猫 🤗

## 项目结构

- `src/`：Electron + React 桌宠客户端
- `resources/`：桌宠图片、音乐和角色资源
- `backend/`：FastAPI + LangGraph + MySQL AI 后端

后端启动方式见 [backend/README.md](backend/README.md)。
